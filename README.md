## Description

Redesign the blob’s movement and
environment to express a specific emotion
(e.g., joy, frustration, panic)

Making the blob more joyful by adding a faster breathing effect, more wobble, a yellow background, different coloured environment and changing the gravity/speed effects
The idea is to make the blob feel more childlike
